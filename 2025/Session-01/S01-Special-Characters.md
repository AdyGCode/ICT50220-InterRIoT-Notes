# Special Characters

There are a number of special symbols we use in electronics, IoT, programming and more. This document provides a list of
some of them, plus how to obtain them in various operating systems.

> **Note: **
> 
> Those people who use Linux Desktop on a regular basis, we would appreciate you providing a description of how to
> obtain the symbols provided in the table below.

## Symbols Table

> For ALT codes above 255, you need to use the Unicode input method: hold ALT, press + on the numeric keypad, then type
> the hexadecimal code (e.g. <kbd>ALT</kbd>+<kbd>+</kbd><kbd>2</kbd><kbd>2</kbd><kbd>1</kbd><kbd>E</kbd> for infinity)
> or use the decimal with some OS-specific support.
>
> Codes like <kbd>ALT</kbd>+8451 (℃) require Unicode input or copy-paste since Windows <kbd>Alt</kbd> + numeric keypad
> only supports up to 255 in legacy mode.
>
> For some arrow keys and symbols, the standard <kbd>ALT</kbd> + numeric keypad doesn't produce them; Unicode input
> methods or > character maps might be needed.

## Getting Special Characters...

It is possible to get characters that are not part of the standard US style keyboard using a number of ways.

Below we outline how to obtain them in the three main operating systems.

### Windows

Press <kbd>WIN</kbd>+<kbd>.</kbd> to show the 'character selector'.

Clicking on the "symbols"
![Picture: showing the symbols item in the character selector](../assets/s01-characters-symbols.webp) will take
you to the character section.

Here you will find Language symbols for characters such as the Greek letter omega (<kbd>Ω</kbd>) and Mathematical
symbols for the likes of the times and divide.
