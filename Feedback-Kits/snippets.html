So close, but one small problem.

The code will ask for the number 50 times. Only then will it complete the test to see if the (last entered value) is correct.

Why?

Because your code is not indented correctly.

Here is a similar example. We ask the user to enter a word, or /q to quit.

Will not work

while True:
    the_word = input("Please enter a word, or '/q' to quit")

if len(the_word)<1 and the_word <> "/q":
    print("Please enter a word of at least 5 characters, or '/q' to quit.")
else:
    print("The word was: ", the_word)

This will work

while True:
    the_word = input("Please enter a word, or '/q' to quit")

    if len(the_word)<1 and the_word <> "/q":
        print("Please enter a word of at least 5 characters, or '/q' to quit.")
    else:
        break

if the_word <> "/q":
        print("The word was: ", the_word)
